## 🧠 Academic Research

### Psoriasis Detection Using Deep Learning

My academic research explored psoriasis detection through medical image classification using an ensemble of **EfficientNetV2-S and Swin Transformer**.

Key areas of work included:

- Computer Vision and medical image classification
- CNN and Transformer-based architectures
- Ensemble learning
- Dataset preparation and offline augmentation
- Model evaluation using classification metrics

This project strengthened my foundation in Deep Learning and Computer Vision and encouraged me to explore more advanced AI architectures.

*This was an experimental research project, not a clinically validated diagnostic tool.*
